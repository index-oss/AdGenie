System Architecture

The 5 Core Modules of AdGenie

Module A: User Profiling

Analyzes search history, age group classification (18-25, 26-35, 36-50, 50+), and linguistic preference.

Module B: ML Recommender

Hybrid TF-IDF Cosine Similarity engine with demographic affinity boosting and cold-start fallback.

Module C: Regional Ad Generator

Synthesizes product specs, local dialect, discount badges, and relatable cultural hooks.

Module D: FastAPI Engine

Asynchronous REST endpoints serving recommendations in under 45ms with universal CORS support.

Module E: Monetization Analytics

Real-time CTR tracking, conversion logging, and CPC revenue calculations for publishers.

Modular, decoupled architecture allowing independent scaling and microservice deployment.
Machine Learning Pipeline

How the Recommendation Engine Works Under the Hood

📐 Mathematical Pipeline

  • Corpus Construction: Aggregates product title, category, sub-category, descriptive tags, and benefits.
  • TF-IDF Vectorization: Penalizes frequent stopwords and elevates distinctive product features.
  • Cosine Similarity: Measures the semantic angle between user intent vector Q and catalog item vector D.

⚡ Demographic & Hybrid Scoring

Score = W_search * Cosine(Q, D)
      + W_history * Cosine(H, D)
      + W_demo * AgeAffinity(UserAge, ProdAge)
      + W_rating * (Rating / 5.0)

Ensures that even short or misspelled searches surface age-appropriate, high-relevance recommendations.

Zero cold-start deadlocks: New visitors automatically receive verified high-rated community favorites.
